# CAS Lab look for Claude

A background and color theme for the Claude desktop and mobile apps. It shows the CAS Lab
triangle-and-brain logo and the CAS LAB lettering on a dark navy background, with a neural
tree whose points of light travel up from its roots, through the trunk, into the brain. The
panels have a medium frosted-glass effect, and the colors are tuned to the CAS Lab palette
(tree blue `#4aa3ff`, brain green `#3ef5a8`). It is a dark-mode look. If your system asks
for reduced motion, the moving lights are hidden.

The terminal and editor versions of Claude Code do not draw backgrounds.

## Install

At the prompt of a terminal session:

```
/plugin install cas-lab-look --marketplace LittleHenderson/claude-cas-lab-background
```

From a shell:

```bash
claude plugin install cas-lab-look --marketplace LittleHenderson/claude-cas-lab-background
```

Answer `y` to add the marketplace, then pick the user scope so it loads in every session.

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then
Plugins, Add marketplace with `LittleHenderson/claude-cas-lab-background`, then Add plugin.
